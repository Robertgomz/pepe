Política de privacidad de Pepe

Última actualización: septiembre de 2026.

Qué es Pepe

Pepe es un asistente privado de uso familiar. No se ofrece al público ni tiene fines comerciales.

Datos que usa

  • Mensajes del grupo familiar de WhatsApp donde participa Pepe, para detectar eventos y responder solicitudes.
  • Acceso a Google Calendar de la cuenta del administrador, solo para crear, leer y modificar eventos familiares.

Cómo se usan

Los datos se usan únicamente para crear eventos, recordatorios y listas de la familia. No se venden, no se comparten con terceros con fines publicitarios y no se usan para ningún otro propósito.

El uso de la información recibida de las API de Google cumple con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Almacenamiento y eliminación

Los datos se guardan en un servidor privado del administrador. Cualquier integrante de la familia puede pedir que se eliminen sus datos escribiendo al contacto indicado abajo.
